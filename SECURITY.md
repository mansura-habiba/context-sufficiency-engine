# Security policy

This is a **research MVP**, not an independently security-audited production gateway. It processes potentially sensitive enterprise evidence and should be embedded **only behind a trusted authentication and authorization boundary**.

Report vulnerabilities privately to the repository maintainers using GitHub's private vulnerability reporting feature where available. Please do not open public issues containing real credentials, confidential data, or reproduction payloads involving customer systems.

Please include affected version/commit, a minimal synthetic reproduction, the security impact, and a suggested mitigation. We aim to acknowledge and triage responsible reports, but do not promise a specific response SLA.

Read [the threat model](docs/security.md) before any external deployment.
